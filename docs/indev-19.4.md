# Indev 19.4 本地开发

版本显示为 **Indev 19.4**，内部版本为 `19.4.0-indev`，开发分支为 `codex/indev-19.4`。

## 启动界面 A/B

「设置 → 外观 → 界面风格」提供 A / B 切换。选择保存到本机，重启后继续使用。

- A：现有的背景、侧栏与启动区域；旧配置默认使用 A。
- B：之前试验的 shadcn 界面扩展为共用外框，覆盖启动、实例与实例详情、账户、发现、社群友链、下载任务和设置；共用侧栏、顶部栏、分区导航、卡片、表单和弹窗样式，并支持浅色／深色模式。

两种界面使用同一套账户、实例、校服配置和磁贴组件。切换更换显示风格，不复制游戏或存档；在同一设置页切换时保留页面状态。放牛、Esc 清空和启动限制继续使用原有实现。

外观设置新增「更真实的物理放牛」，默认关闭，仅在 A 主页生效。开启后，磁贴、侧栏、账户与启动区域、日期文字和圆形地球仪均参与碰撞；移动或缩放磁贴会挤开牛。容量按可用空间计算，开启功能或缩小窗口后超出容量时优先保留灰色牛；B 沿用原有放牛效果。

## 顶部公告横幅

标题栏下方按主题色显示社群公告，A / B 主界面共用；公告为空或只有空白时不显示，也不预留空间。内容沿用校服共享配置的 `announcement` 字段，在「设置 → 校服维护 → 公告」编辑；本地应用预览后立即显示，群友端沿用已有的双来源共享配置。横幅每分钟刷新，标题栏和放牛区域随实际高度布局；「查看公告」可阅读完整的长公告。当前随包公告仍为空，没有添加演示内容。

## GitHub / GitLab 双来源

- 更新检查依次读取两个仓库的公开更新清单，比较可用版本；每个来源的 API 仅在公开清单不可用时作为备用。
- 更新安装包只接受 `Supaio/SAUMCL` 的 GitHub Release，以及 `Supaio/saumcl` 的 GitLab Release / 软件包地址。下载前检查候选下载入口，可用的入口交给现有任务下载器；下载开始后发生传输中断时仍使用原有任务重试流程。
- 校服共享配置与社群清单先尝试 GitHub，再尝试 GitLab；两端均不可用时使用原有缓存和随包配置。
- 维护页展示两个校服配置地址。公开配置修改后，需同步发布两端的同名文件。
- 正式发行时复用同一批经校验的 Windows / Linux 成品，上传到两个仓库。

Microsoft 正版登录继续沿用已使用的 SJMCL OAuth 应用。本轮不注册新的云服务，也不新增付费服务。
