SAUMCL **Indev 19.0.1**，面向四川农业大学玩家社群的预发行版本。

本启动器面向四川农业大学在校学生、毕业校友及“四川农业大学川泷MC服群（CLMC）”（群号：719489600）群友提供支持。请勿向上述范围以外的人员转发本社群发行包。

本次发布包含：

- 首次启动欢迎窗口及“设置 → 关于”中的红字社群提醒。
- 启动时检查本项目的新版，提示更新说明，并支持下载更新。
- 左侧自适应导航、校服背景和 SAUMCL 标识。
- 简体中文、繁体中文和英语；资源下载使用 Modrinth。
- Microsoft 正版账号登录，验证仍沿用 SJMCL 的 OAuth 应用。

下载与运行：

- **Windows x64**：下载 `SAUMCL.exe`，放入单独的文件夹后运行。
- **Linux x64**：下载 `SAUMCL`，执行 `chmod +x ./SAUMCL` 后运行。Linux 更新通过发布页手动下载。
- `SHA256SUMS.txt` 提供两个文件的 SHA-256 校验值。

首次启用更新检查，请先手动安装本次附件；之后发布更高版本时会提示更新。

这是 Indev 预发行版本，部分功能仍在调整。智能与扩展插件功能暂时停用；校服目前暂停服务，尚未完成校服联机验证。

项目基于 [SJMCL](https://github.com/UNIkeEN/SJMCL)，源码与许可证随 Git 标签提供，详见仓库中的 `LICENSE` 与 `LICENSE.EXTRA`。
