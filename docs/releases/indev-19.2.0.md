SAUMCL Indev 19.2，面向四川农业大学玩家社群的预发行版本。

本启动器面向四川农业大学在校学生、毕业校友及“四川农业大学川泷MC服群（CLMC）”（群号：719489600）群友提供支持。请勿向上述范围以外的人员转发本社群发行包。

本次更新：

- 在启动游戏按钮上方新增小型“一键进入校服”按钮，目前置灰禁用，待校服同步接通后再启用。
- 追加两条由社群提供的川农牛冷知识。
- 将 Next.js 及配套工具升级至 16.4.1，修复本次依赖安全审计报告的漏洞。
- 新增川农牛互动：每点击一次右上角的牛按钮，就从窗口顶部落下一只牛；按 Esc 清空。
- 牛之间可以碰撞、堆叠，也能落在主页账户卡片和启动游戏框上，从边缘滑落；碰撞位置随窗口和卡片布局变化更新。
- 调整边界绘制和堆叠碰撞，牛在下落和碰撞时会旋转，堆稳后逐渐停止；数量上限按窗口容量调整，最多 500 只，放满后不再新增。
- 牛的大小在原来大小的 50%～200% 之间随机变化；每次生成有 0.0082% 的概率出现一只灰色牛，附带银色闪光和星芒特效。
- 抽到灰色牛后，在 Esc 提示旁显示本机累计数量；清空画面或重启启动器后保留记录。
- 放牛时左侧导航栏自动收为图标模式，清空后恢复原来的导航样式。
- 超过 100 只牛时暂时禁止启动游戏，按 Esc 清空后恢复；正常启动游戏时自动清空牛，避免同时占用性能。

下载与运行：

- Windows x64：下载 `SAUMCL.exe`，放入单独的文件夹后运行。
- Linux x64：下载 `SAUMCL`，执行 `chmod +x ./SAUMCL` 后运行。Linux 更新通过发布页手动下载。

这是 Indev 预发行版本，部分功能仍在调整。校服目前暂停服务，尚未完成校服联机验证。
