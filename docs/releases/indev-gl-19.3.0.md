SAUMCL Indev GL 19.3，面向四川农业大学玩家社群的预发行版本。

本启动器面向四川农业大学在校学生、毕业校友及“四川农业大学川泷MC服群（CLMC）”（群号：719489600）群友提供支持。请勿向上述范围以外的人员转发本社群发行包。

本次更新：

1. 版本名称统一调整为 Indev GL 19.3，标识 GitLab 迁移版本。
2. 项目源码、Windows／Linux 安装包及发行入口迁移至 GitLab。
3. 更新检查、校服共享配置、社群清单、项目链接与问题反馈入口改用 GitLab。
4. 新增 GitLab 双平台构建、安装包校验与发行流程，沿用 Indev 19.3 的原有界面和功能。

GitHub 旧版首次迁移需要手动下载并替换启动器；游戏、实例和存档请保留。shadcn/ui 界面仍为独立试用，不包含在本次正式迁移包内。

下载与运行：

- Windows x64：下载 `SAUMCL.exe`，放入单独的文件夹后运行。
- Linux x64：下载 `SAUMCL`，执行 `chmod +x ./SAUMCL` 后运行。Linux 更新通过发布页手动下载。

这是 Indev 预发行版本，部分功能仍在调整。校服目前暂停服务，尚未完成校服联机验证。
