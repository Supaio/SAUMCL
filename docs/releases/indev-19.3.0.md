SAUMCL Indev 19.3，面向四川农业大学玩家社群的预发行版本。

本启动器面向四川农业大学在校学生、毕业校友及“四川农业大学川泷MC服群（CLMC）”（群号：719489600）群友提供支持。请勿向上述范围以外的人员转发本社群发行包。

本次更新：

1. 新增主页服务器磁贴，校服固定显示在第一项，其他服务器从各实例的多人游戏列表读取；显示服务器状态、当前与下一周目，合并“一键进入校服”入口。
2. 接入校服客户端准备流程：配置整合包直链后，支持下载、校验、安装客户端与所需 Java，并在启动后直接连接校服；客户端版本更新时创建独立实例，保留旧实例和存档。
3. 新增本地维护 Key 验证、校服配置草稿、公告、预览与导出工具。维护授权长期有效，不随周目或人员交接自动失效；所有者初始化授权公钥后可启用。
4. 新增游玩日历，显示今天、本周与累计游玩时长，以及本周和累计游玩天数；主页磁贴支持拖动、缩放和布局记忆。
5. 主页右上角新增 UTC+8 日期、时间及每日 Minecraft 主题短句；新增可拖动、自转的倾斜地轴地球仪，默认关闭，可在外观设置开启。
6. 新增“福利速递”和“社群友链”，支持收集官方福利消息并由维护人员审核后发布，展示社群、项目、语音平台与各大学友链；公开清单和校服配置通过本项目的静态文件更新。
7. 社区新闻固定保留 MUA，移除玩家对新闻数据源的管理入口。
8. 修复满屏放牛后缩小窗口导致超量牛剧烈碰撞的问题，按新窗口容量调整数量与位置，并优先保留灰色牛；追加一条社群提供的冷知识。
9. 修复近期新增的 Rust 依赖安全问题，保留旧维护 Key 的验证兼容性，并修正仓库关闭 Issues 时安全审计误失败的流程。

校服地址与客户端整合包仍待维护人员填写。维护草稿保存或导出仅影响本机，公开同步需由具备仓库权限的人员发布对应配置文件。主程序仍有部分上游历史依赖告警待跟进。

下载与运行：

- Windows x64：下载 `SAUMCL.exe`，放入单独的文件夹后运行。
- Linux x64：下载 `SAUMCL`，执行 `chmod +x ./SAUMCL` 后运行。Linux 更新通过发布页手动下载。

这是 Indev 预发行版本，部分功能仍在调整。校服目前暂停服务，尚未完成校服联机验证。
