SAUMCL Indev 19.1，面向四川农业大学玩家社群的预发行版本。

本启动器面向四川农业大学在校学生、毕业校友及“四川农业大学川泷MC服群（CLMC）”（群号：719489600）群友提供支持。请勿向上述范围以外的人员转发本社群发行包。

本次更新：

- 首页实例切换清单新增搜索框，可按名称、版本、加载器和描述查找实例。
- 实例详情页新增“设为启动实例”按钮，点击后直接更新首页选择，并显示当前选中状态。
- 本地模组搜索支持中文、英文、拼音全拼和首字母，可按 Mod ID 查找。例如输入 `wu`、`wupin` 或 `wpglq`，可找到带“物品管理器”中文译名或中文文件名的 JEI。
- 修复 GTNH 2.8.4 等包含 lwjgl3ify 的整合包使用现代 Java 时弹出二次启动设置窗口的问题，并修复相关 MultiMC 整合包的文件导入。
- 启动进度窗口底部新增社群冷知识；维护者可在 `public/trivia.txt` 中逐行增删内容，随下次构建发布。

下载与运行：

- Windows x64：下载 `SAUMCL.exe`，放入单独的文件夹后运行。
- Linux x64：下载 `SAUMCL`，执行 `chmod +x ./SAUMCL` 后运行。Linux 更新通过发布页手动下载。

这是 Indev 预发行版本，部分功能仍在调整。校服目前暂停服务，尚未完成校服联机验证。
