# Indev 19.3 游玩日历

启动页的游玩日历磁贴显示当月日历、今天的时长、本周游玩天数与时长、累计游玩天数与时长。有游玩记录的日期会着色，悬停可查看当天时长；本周按本机时间的周一至周日计算。累计天数按有游玩记录的不同日期计算，同一天多次启动只计一天，不将累计小时数换算成天数。

统计本机通过 SAUMCL 启动并监测到的所有游戏实例。沿用原来的计时起点：游戏日志进入渲染初始化阶段后开始，直到游戏进程结束；后台、菜单及挂机时间也会计入，多开实例分别累计。

旧版本的实例记录只有累计秒数，首次使用时会导入累计，无法还原成每天的记录。日统计从新功能开始记录，不将旧累计记作今天的游玩时间。累计导入后独立保留，删除实例不会删除已经记录的日历时长。

记录保存在启动器应用数据目录下的 `playtime.json`，按本机日期归档。运行中的时长每 30 秒刷新显示、每 60 秒保存；游戏结束或正常退出启动器时再次保存。跨午夜按实际日期拆分。启动器退出后无法继续监测仍在运行的游戏；强制关闭时可能丢失尚未保存的一小段记录。

保存使用临时文件替换；读到损坏或不支持的统计文件时保留原文件，并显示读取失败，不会用零覆盖原记录。磁盘满或无写入权限时显示保存失败，保留内存中的统计供后续重试。

日历和服务器磁贴均可拖动标题栏移动，拖动右边、下边或右下角调整大小；位置和尺寸在本机记住。拖动时其他磁贴保持原位，松手后就近避让；缩放遇到邻近磁贴时停止扩张。磁贴区在当前屏幕内自适应并排或换行，不增加整体滚动条；日历调整留白和日期格，内容确实放不下时才在内部滚动，底部游戏启动按钮保持可见。操作与后续磁贴规范见 [启动页磁贴](home-tiles.md)。此磁贴为内置功能，不需要开启扩展插件。
