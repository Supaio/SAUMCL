# 放牛与窗口缩放

牛数量按当前窗口面积限制，最多 500 只；满了后停止新增。超过 100 只时禁用游戏启动，按 Esc 可清空，正常发起游戏启动时也会清空。

Indev 19.3 修复缩小窗口后保留超量牛、被挤到边缘反复碰撞的问题。有效窗口尺寸改变时同步更新容量与实际数量；超量时优先保留灰色牛，再保留较早放出的普通牛。剩余牛的位置按可用空间重新映射，清除缩放瞬间的运动速度，保留朝向，随后继续进行原有物理模拟。放大窗口后可以继续放牛，不会自动恢复收回的普通牛。

最小化产生的零尺寸不清空牛；恢复到有效尺寸后再调整。累计抽中过的灰色牛次数独立保存，缩放与 Esc 均不减少累计次数，也不会重复计数。

验证包含满屏后缩小到 112 只容量、启动框碰撞、稳定后的位置和旋转、灰色牛保留、重新放大后继续新增、零尺寸恢复：

```powershell
node --experimental-strip-types scripts/qa/cow-drop-regressions.mjs
```
